A golden record is what a correct artefact must contain, **written down before anything is graded**. The grader never sees this file. `/gate` compares the artefact against it only *after* the context-separated grade comes back, and records "Required facts met n/n" in the decision.

## Part 1: Golden records (text artefacts: descriptions, glossary terms, contract claims)

Six fields per record:

| Field | What it holds |
|---|---|
| **Required facts** | What the artefact must state. Each one separately checkable. |
| **Required exclusions** | What the artefact must leave out, or must not conflate. |
| **Forbidden claims** | Specific wrong statements. If one appears, the artefact fails whatever else it gets right. |
| **Evidence** | File and section, or file and line range. Must contain the claim. |
| **Ambiguity** | Whether the evidence settles this, and what to do if it doesn't. |
| **Severity** | What it costs if this is described wrongly. |

You're grading claims, not prose. Two differently worded artefacts can both pass.

## Part 2: Golden data (data transformations)

Input rows and expected output rows, reviewed by someone with authority. A test with a `T-` ID compares actual output against them.

| Case | Kind | What it represents | Input | Expected | Traces to |
|---|---|---|---|---|---|
| GD-01 | representative | the common case | `input/gd01.csv` | `expected/gd01.csv` | `BR-01`, `AE-03` |
| GD-02 | edge | boundary: month-end, null, zero, negative | | | `BR-04` |
| GD-03 | exclusion | a row that must **not** appear | | | `BR-02` |
| GD-04 | adversarial (Tier 3) | a case built to tempt a plausible wrong answer | | | |

## Rules

1. **Expected results come from authority, not from the code.** A golden file generated by running the implementation only proves the code agrees with itself.
2. **Small and explained.** Every record and row exists for a reason, written down.
3. **No production `restricted` data.** Synthesize it, or use masked extracts approved by the steward.
4. **Kept away from the generator and the grader.** A grader that's been told the answer is checking agreement, not correctness.
5. **Every defect the gate misses and production finds becomes a new record** (`registers/failure-library.md` → regression asset).
